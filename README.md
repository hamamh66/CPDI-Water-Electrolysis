# Certified Physical Decision Intelligence for Water Electrolysis

**Repository:** `Certified-Physical-Decision-Intelligence-Electrolysis`

## Short Description
Reference implementation of the Certified Physical Decision Intelligence (CPDI) framework for water electrolysis, providing reproducible variational-equilibrium optimization, identifiability certification, uncertainty quantification, structural robustness analysis, and cross-technology evaluation across alkaline, PEM, and AEM electrolyzers.

## Overview
This repository accompanies the research article:

**Certified Physical Decision Intelligence for Water Electrolysis: Variational Equilibrium, Identifiability Guarantees, and Bubble-Regime Selection across Alkaline, PEM, and AEM Systems**

It contains:
- Reproducible implementation of the CPDI framework
- Mechanistic electrochemical models
- Variational optimization algorithms
- KKT and dual analysis
- Identifiability certification
- Bootstrap uncertainty analysis
- Structural uncertainty analysis
- Figure and table generation
- Reproducibility scripts
